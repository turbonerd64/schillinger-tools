# Schillinger Tools Studio

Live Studio: **https://schillingertools.arman.love**  
Repository: **https://github.com/turbonerd64/schillinger-tools**

## 1. System Vision & Overview

The Schillinger System of Musical Composition is one of the most rigorous, unified mathematical theories of music ever created. Developed by Russian-American theorist, mathematician, and composer **Joseph Schillinger (1895 to 1943)**, the system treats rhythm, melody, harmony, counterpoint, and orchestration as functions of algebraic equations, periodic interferences, and geometric projections.

Schillinger taught many of the 20th century's most influential composers and arrangers:
- **George Gershwin:** Composed *Porgy and Bess* and *An American in Paris* while studying under Schillinger.
- **Glenn Miller:** Created the legendary Miller sound and arranged *Moonlight Serenade* using Schillinger distribution formulas.
- **John Barry, Henry Mancini, Benny Goodman, Carmine Coppola, and Quincy Jones:** Leveraged Schillinger techniques for film scores, big band orchestrations, and modular arrangements.

**Schillinger Tools Studio** is an open-source, dependency-free web workstation that transforms Schillinger's theoretical treatises into an intuitive, real-time interactive composition environment.

## 2. Core Studio Modules

### Module 1: Rhythm Resultant Studio (Book I: Theory of Rhythm)
The Rhythm Studio visualizes and synthesizes rhythmic interferences generated by periodic wave synchronization:

1. **Binary Synchronization ($r = a \div b$):**
   - Synchronizes two generators $a$ and $b$ ($a > b$) over their common product cycle $L = a \times b$.
   - Computes resultant duration series, attack points, and phase coincidence moments.
   - **Coprime Polyrhythm Metric Downbeat Accents (Book I, Ch. 2 & 8):** In standard polyrhythms where $a$ and $b$ are coprime (such as 3:2, 4:3, 5:2, 5:4, 7:4), phase coincidence occurs solely at $t = 0$. The engine assigns metric downbeat accents on major generator attacks when grouped by $a$ or $ab$, and on minor generator attacks when grouped by $b$, reflecting authentic musical phrasing.
2. **Fractioning Around the Axis of Symmetry ($a \div \underline{b}$):**
   - Synchronizes generator $a$ against generator $b$ batched in groups of length $a$ across $L = a^2$.
   - Generates symmetrical, palindromic resultant patterns with $N_b = a - b + 1$ minor groups.
3. **Three-Generator Interference ($r = a \div b \div c$):**
   - Synchronizes three periodic streams across $L = a \times b \times c$.
   - Simultaneously derives the primary rhythmic theme $r$ and the complementary countertheme $r'$, enabling immediate two-part contrapuntal rhythmic generation.
4. **Metric Grouping & Bar Framing:**
   - Group by $ab$: frames the entire common cycle as a single macro measure.
   - Group by $a$: divides the timeline into measures of length $a$ with downbeat accents on each bar line.
   - Group by $b$: divides the timeline into measures of length $b$.
5. **Permutations & Variations:**
   - **Retrograde:** Reverses duration series along the temporal axis.
   - **Circular Permutations:** Rotates duration series step-by-step ($C_1, C_2, \dots, C_n$), preserving aggregate cycle duration while generating new syncopated grooves.
6. **Multi-Lane Visualizer & Synthesis:**
   - Vector graphics rendering Generator $a$, Generator $b$, pulse grid, and Resultant $r$ with accent highlights.
   - Native Web Audio API synthesis generating resonant physical percussion models (woodblock, clave, rimshot).

### Module 2: Harmony Studio (Book II & Book V)
The Harmony Studio provides a complete compositional environment for non-functional and algebraic harmonic cycles:

1. **Three Harmonic Systems (Book V):**
   - **Type I: Diatonic System (Chapter 2):**
     Root progressions moving through parent scale degrees ($C_3$ Thirds, $C_5$ Fifths/Fourths, $C_7$ Steps). Tertian chords are constructed strictly from in-scale pitches across 7 Church Modes and 8 Synthetic/Symmetric scales.
   - **Type II: Diatonic-Symmetric Invariant System (Chapter 4):**
     Roots progress along diatonic scale steps, but each chord maintains an invariant chord density and quality (e.g., all Dominant 7ths, all Minor 7ths, or all Major 7ths), injecting modal interchange and chromatic borrowing.
   - **Type III: Symmetric System (Chapter 5):**
     Roots move by equal chromatic semitone divisions of the 12-semitone octave based on roots of 2:
     - $C_6$ ($\sqrt{2}$): Tritone axis (6 semitones, 2 polar tonics)
     - $C_4$ ($\sqrt[3]{2}$): Augmented / major third axis (4 semitones, 3 tonics, e.g., Coltrane changes $C \to E \to A\flat$)
     - $C_3$ ($\sqrt[4]{2}$): Diminished / minor third axis (3 semitones, 4 tonics)
     - $C_2$ ($\sqrt[6]{2}$): Whole-tone axis (2 semitones, 6 tonics)
     - $C_1$ ($\sqrt[12]{2}$): Chromatic semitone axis
     - $C_0$: Static root axis with internal voice permutations
2. **Variable Chord Density Engine ($S_5, S_7, S_9$):**
   - Global chord density setting ($S_5$ Triads, $S_7$ Sevenths, $S_9$ Ninths) serves as the baseline default.
   - **Per-Chord & Batch Range Overrides:** Click any individual chord or drag across a group of chords in the Master Progression Lane to switch density to Triad, 7th, or 9th on the fly.
   - Sculpt tension arcs: open with rich 9ths, build through 7ths, and resolve to a clean triad.
3. **Algebraic Voice-Leading Engine (Book V, Ch. 2, Sections C, D, E):**
   - **Minimal Motion (Greedy):** Euclidean nearest-neighbor voice assignment preventing abrupt octave jumps.
   - **Clockwise Transformation ($T_{\circlearrowright}$):** Cyclically shifts factor roles forward ($1 \to 3 \to 5 \to 7 \to 1$).
   - **Counterclockwise Transformation ($T_{\circlearrowleft}$):** Cyclically shifts factor roles backward ($1 \to 7 \to 5 \to 3 \to 1$).
   - **Constant Tone Transformation ($T_{\text{const}}$):** Statically locks shared pitch classes in their exact registers while smoothly moving remaining voices.
   - Seamlessly adapts across heterogeneous density transitions ($S_5 \leftrightarrow S_7 \leftrightarrow S_9$).
4. **Master Progression Lane & Modal Interchange:**
   - Visual sequence displaying active chords, Roman numerals, density tags, and color-coded modal origins.
   - Floating Inspector: click or drag-select chords to batch-swap modes (e.g., borrow from Phrygian, Dorian, or Hungarian Minor) or change chord densities.
5. **Parallel Mode Rails:**
   - Multi-lane comparative view mapping parallel Church modes and synthetic scales against the exact same formula. Click any cell to audition or swap it into the master progression.
6. **Interactive Visualizers:**
   - **Virtual 88-Key Piano:** Lights up active chord voicings, roots, and extensions in real time.
   - **Interactive Guitar Fretboard:** Displays pitch classes and scale degrees across 15 frets in standard tuning.
7. **Multi-Format Export:**
   - Standard Chord Symbols, Roman Numerals, and Nashville Number System.
   - Standard MIDI File (.mid) download with polyphonic chord voicings and tempo metadata.

## 3. Technology Stack & Architecture

- **Framework:** React 19 with TypeScript 6.
- **Build System:** Vite 8 with fast HMR.
- **Styling:** Tailwind CSS 3.4 with retro-neomorphic high-contrast theme.
- **Audio Engine:** Pure Web Audio API synthesis (zero external audio libraries or soundfont downloads).
- **MIDI Layer:** Handcrafted, dependency-free binary Standard MIDI File (SMF Format 0) encoder.
- **Testing:** Vitest test suite with 22 automated unit and integration tests.
- **Containerization:** Multi-stage Docker build with Alpine Linux and Nginx (< 15 MB memory footprint).

## 5. Mathematical Formulations Quick Reference

### Rhythm Synchronization

| Technique | Formula | Common Cycle Length ($L$) | Musical Character |
| :--- | :--- | :--- | :--- |
| **Binary Sync** | $r = a \div b$ | $L = a \times b$ | Primary syncopated resultant groove |
| **Fractioning** | $r = a \div \underline{b}$ | $L = a^2$ | Symmetrical, palindromic rhythmic structures |
| **Trinomial Sync** | $r = a \div b \div c$ | $L = a \times b \times c$ | Polyrhythmic polyphony with complementary countertheme $r'$ |

### Harmonic Root Movement

| Movement Code | Formula System | Interval | Description |
| :--- | :--- | :--- | :--- |
| $C_3 \downarrow$ | Type I Diatonic | 3rd Down (5 scale steps) | Mediant fall; maximum common-tone retention |
| $C_3 \uparrow$ | Type I Diatonic | 3rd Up (2 scale steps) | Ascending mediant motion |
| $C_5 \downarrow$ | Type I Diatonic | 5th Down (3 scale steps) | Functional circle of fifths cadence |
| $C_5 \uparrow$ | Type I Diatonic | 5th Up (4 scale steps) | Ascending fifth / subdominant motion |
| $C_7 \downarrow$ | Type I Diatonic | Step Up (1 scale step) | Stepwise motion; zero adjacent common tones |
| $C_7 \uparrow$ | Type I Diatonic | Step Down (6 scale steps) | Descending stepwise motion |
| $C_6$ | Type III Symmetric | 6 semitones ($\sqrt{2}$) | Tritone polarity (2 tonics dividing octave equally) |
| $C_4$ | Type III Symmetric | 4 semitones ($\sqrt[3]{2}$) | Major thirds / augmented axis (Coltrane changes, 3 tonics) |
| $C_3$ | Type III Symmetric | 3 semitones ($\sqrt[4]{2}$) | Minor thirds / diminished axis (4 tonics) |
| $C_2$ | Type III Symmetric | 2 semitones ($\sqrt[6]{2}$) | Whole-tone axis (6 tonics) |
| $C_1$ | Type III Symmetric | 1 semitone ($\sqrt[12]{2}$) | Chromatic semitone axis |
| $C_0$ | Type III Symmetric | 0 semitones | Static root with internal voice transformation |

## 6. Development & Deployment

### Local Setup
```bash
# Clone repository
git clone git@github.com:turbonerd64/schillinger-tools.git
cd schillinger-tools

# Install dependencies
npm install

# Start local development server (http://localhost:5173)
npm run dev

# Run test suite
npm test

# Build production bundle
npm run build
```

### Docker Production Deployment
```bash
# Build and start container in detached mode
docker compose build && docker compose up -d

# Check container status
docker compose ps

# View container logs
docker compose logs -f
```
